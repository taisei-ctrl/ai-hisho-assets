AI秘書

LINEで話しかけるだけの、あなた専用の秘書

できること

  • 毎朝・夕方など決まった時刻に、LINEで「今日の予定」と「やること（ToDo）」をまとめてお知らせします。
  • 「明日の予定は?」「ToDo見せて」とLINEで聞くと、Googleカレンダーと Google ToDo リストを見て答えます。
  • 「来週火曜の15時に打ち合わせを入れて」「請求書を送る、をToDoに足して」と頼むと、代わりに登録します（ご本人が「いろいろ任せる」を選んだ場合のみ）。
  • 期限の近いToDoや、予定の重なりに気づいたらお知らせします。

使い方

  1. LINEで「AI秘書」を友だち追加します。
  2. 案内に沿って、使うGoogleアカウントのアドレスと、そのアカウントを何に使っているか（カレンダー／ToDo）を選びます。
  3. 届いたリンクを開き、Googleの画面で内容を確かめて「許可」を押します。AI秘書が求めるのは、選んだ用途の分の許可だけです。
  4. あとは LINE で話しかけるだけです。

Googleのデータの扱い

AI秘書は、ご本人が許可したGoogleアカウントの カレンダーの予定 と ToDoリスト を、ご本人へのお知らせと、ご本人に頼まれた登録・変更のためだけに使います。 広告に使ったり、第三者に販売したり、AIの学習に使ったりすることはありません。 許可はいつでも取り消せます（LINEで「接続を外す」、または Googleアカウントの設定）。

くわしくは プライバシーポリシー をご覧ください。

About AI Hisho (English)

AI Hisho ("AI Secretary") is a personal secretary service used through LINE messenger. With the user's permission, it reads the user's Google Calendar events and Google Tasks to send daily schedule and to-do summaries in LINE, answers questions such as "What's on my calendar tomorrow?", and — only if the user chooses the "delegate" option — adds or updates calendar events and tasks when the user asks. Google user data is used only to provide these user-facing features. It is never sold, used for advertising, or used to train AI models. See our Privacy Policy.
