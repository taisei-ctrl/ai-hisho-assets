# AI秘書 アセット

LINEのAI秘書が参照する公開画像の置き場です。
LINEのサーバーが直接取りに来るため、このリポジトリは公開にしてあります。

## 参照のしかた

ハブ側（GAS）のスクリプトプロパティ `ICON_BASE_URL` に、
このリポジトリの `icons` ディレクトリのURLを設定すると読み込まれます。
将来ここから独自ドメインへ引っ越す場合も、そのプロパティを書き換えるだけで済みます。

**画像を差し替えるときの注意**: ファイル名は変えないこと。
利用者の設定には画像のURLがそのまま保存されているため、名前を変えると
その顔を選んでいた人の表示が消えます。

## アイコンの切り抜き（2026-09-15）
- LINEのトーク画面では丸く小さく表示されるため、`icons/1〜8.png` は顔が円いっぱいに入るよう拡大切り抜き済み（さくらのアイコンと同程度）。
- 元画像は `icons/original/` に保存。切り抜き位置（顔の中心と枠の大きさ）は momo-hub 側の作業記録（HANDOFF.md）を参照。
- `faces.png`（選択用の一覧）は元の構図のまま。
